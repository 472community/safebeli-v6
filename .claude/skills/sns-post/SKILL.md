# SNS 발행 (텔레그램 유입용)

목표는 하나다: **SNS 게시물 → 텔레그램 유입 → 커뮤니티 정착.**
좋아요가 아니라 `?start=` 링크를 타고 들어온 사람 수가 성과다.

## 시작 전 반드시

`marketing/templates.json` 과 `marketing/brand.json` 을 읽는다.
`templates.json` 에 영상 유형별 구조(비트별 대본 흐름)와 규칙이 있다.
`brand.json` 에 커뮤니티 이름·타깃·톤·콘텐츠 축·금지 표현이 거기 있다.
**`telegramValue` 가 비어 있으면 글을 쓰지 말고 먼저 물어본다** — 텔레그램에 들어와야만
얻는 게 뭔지 모르는 상태로 쓴 CTA 는 유입을 못 만든다.

## 작업 순서

1. **큐 확인** — `marketing/content/queue.json` 에서 최근 글의 주제·콘텐츠 축 중복을 피한다.
2. **유입 데이터 확인** — `node marketing/collect-leads.js --report` 로 지금까지
   어느 글이 사람을 데려왔는지 본다. 잘 먹힌 축을 변주하고, 죽은 축은 버린다.
3. **초안 작성** — 아래 규칙대로 플랫폼별 본문을 쓰고 큐에 `status: "draft"` 로 추가한다.
   **본인 경험담을 지어내지 않는다.** "내가 틀렸던 것" 축은 대표님께 실제 사례를 받아서 쓴다.
4. **미리보기** — `node marketing/publish.js --id <id> --now` (드라이런). 렌더된 본문을 보여준다.
5. **승인 받기** — 실제 발행은 외부 공개 행위다. 사용자가 명시적으로 "올려" 라고 하기 전에는
   `--live` 나 `go.js --yes` 를 절대 실행하지 않는다.
6. **발행**
   - 원클릭(권장): `node marketing/go.js` — 초안 전체를 미리보기로 보여주고, 확인 한 번에
     모든 SNS 로 동시 발행한다. 사용자가 직접 실행하는 명령이다.
   - 예약: `status` 를 `scheduled` 로 바꾸고 커밋·푸시 → 시각이 되면 GitHub Actions 가 자동 발행

## 영상 유형 (두 가지만 있다. 섞지 않는다)

`templates.json` 의 구조를 그대로 따른다. 큐 항목에 `type` 을 반드시 적는다.

### `inflow` — 유입 영상 (텔레그램 입장이 목적)
서사 순서가 고정돼 있다: **판 비판 → '우리가 당해왔다' → '나도 깡통 찼다' →
'안 당하는 법을 공부 중이다' → '보고 도움이 되면 좋겠다' → 텔레그램**

- 화자는 늘 **'나도 당했고 지금 공부 중인 사람'**. 전문가 포지션을 취하는 순간 무너진다.
- 후킹의 비판 각도를 **매번 바꾼다**. 같은 비판 반복은 두 번째부터 안 먹힌다.
  이미 쓴 각도: 수익률 인증 조작 / 조회수 수익 구조 / 정보 과잉과 근거 부재
- 비판 대상은 **판의 구조**다. 특정 인물·채널 비방은 금지.
- 수익 인증, 성공담, 특정 코인 언급 금지. 넣는 순간 비판했던 그 판과 같아진다.
- CTA 는 텔레그램 하나. **거래소 레퍼럴은 유입 영상에서 절대 꺼내지 않는다.**

### `education` — 교육 영상 (실력 증명이 목적)
통념 → 반박 → 증명 → 한 줄 정리. CTA 는 약하게, 없어도 된다.

- 개념은 아낌없이 푼다. 여기서 아끼면 실력 증명이 안 된다.
- **현재 시세 판단·전망은 넣지 않는다.** 그건 포스타입(유료) 영역이다.

## 큐 항목 형식

```json
{
  "id": "2026-09-05-<슬러그>",
  "status": "scheduled",
  "publishAt": "2026-09-05T19:00:00+09:00",
  "platforms": ["telegram", "threads", "instagram"],
  "text": "기본 본문 ... {{link}}",
  "variants": { "instagram": "인스타 전용 본문 ... {{link}}" },
  "media": ["images/2026-09-05.jpg"],
  "videoUrl": "videos/2026-09-05.mp4",
  "title": null,
  "tags": []
}
```

영상 글은 `platforms` 를 `["tiktok", "instagram", "youtube"]` 로 두고 `videoUrl` 하나만 적는다.
`media`/`videoUrl` 은 `MARKETING_MEDIA_BASE_URL` 기준 상대경로로 쓴다.
촬영 대본은 `$script` 배열에 초 단위로 적어둔다 (발행기는 무시한다).

- `status` — `draft`(승인 전, **자동 발행 안 됨**) → 승인되면 `scheduled` 로 바꾼다.
  발행 후 `posted`, 일부 실패 시 `partial`, 취소는 `canceled`.
  **초안은 반드시 `draft` 로 넣는다.**
- `id` 는 `YYYY-MM-DD-슬러그`. 영문 소문자·숫자·하이픈만. **유입 출처 코드가 이 id 로 만들어지므로
  글의 주제를 알아볼 수 있게 짓는다.**
- `publishAt` 은 `brand.json` 의 `timezone` 기준 오프셋으로 쓴다.
- `{{link}}` 는 발행 시 플랫폼·글별 추적 링크로 자동 치환된다.
  **직접 링크를 하드코딩하지 말 것** — 유입 출처가 안 잡힌다.
- 인스타그램은 **이미지나 영상 없이는 발행 불가**. `media`/`videoUrl` 없이 instagram 을 넣지 않는다.
  `videoUrl` 이 있으면 자동으로 릴스가 된다.
- 틱톡·유튜브는 영상이 필수다. 유튜브는 세로 3분 이하면 자동으로 쇼츠가 된다.
- 틱톡은 앱 심사 전까지 비공개로만 올라간다. 초안에 그 사실을 함께 알린다.
- 유튜브 커뮤니티 탭 글은 API 가 없어 자동화 불가.

## 플랫폼별 카피 규칙

| | 길이 | 링크 | 후크 |
|---|---|---|---|
| 텔레그램 | 4096자 | 본문에 직접 | 이미 들어온 사람 대상 — 심화·비하인드 |
| 스레드 | **500자 상한** | 마지막 줄 | 첫 문장에서 승부. 질문형/대비형/역설 |
| 인스타 | 2200자 (앞 125자가 승부처) | 본문 + "프로필 링크" 병기 | 1장차 = 후크, 마지막 장 = CTA |
| 유튜브 | 설명 5000자 | 설명 첫 줄 | 쇼츠 기준 첫 2초 |
| 틱톡 | 캡션 2200자 | 본문 링크는 클릭 불가 → 프로필 안내 | 첫 1초. 텍스트 후크를 화면에 띄운다 |

**영상 규격**: 세로 9:16 (1080×1920), 30~60초, mp4. 세 플랫폼 공통.

**공통**
- 홍보 문구로 시작하지 않는다. 사례·수치·체크리스트·실패담으로 시작한다.
- CTA 는 글마다 하나. `brand.json` 의 `telegramValue` 로 수렴시킨다.
- 해시태그는 인스타 5~10개, 스레드 0~2개. `brand.json` 의 `hashtags` 사용.
- 이모지는 줄당 최대 1개.
- 같은 콘텐츠 축을 연속 2회 쓰지 않는다.
- `brand.json` 의 `banned` 표현은 절대 쓰지 않는다.

## 퍼널 규율 (수익과 직결 — 어기면 계정이 날아간다)

`brand.json` 의 `funnel` 을 따른다. 단계를 건너뛰지 않는다.

- 거래소 레퍼럴은 본문에 `{{ref}}` (또는 `{{ref:거래소명}}`) 으로 쓴다. 링크를 직접 적지 않는다.
- **`{{ref}}` 는 텔레그램과 유튜브 설명란에서만 쓴다.** 스레드·인스타·틱톡에 넣으면
  발행기가 거부한다 — 이 세 곳은 제휴 링크를 스팸으로 판정해 도달을 죽이거나 계정을 제재한다.
  SNS 의 CTA 는 **텔레그램 하나뿐**이다.
- 유튜브 설명란에 `{{ref}}` 를 쓸 때는 유료 프로모션 표시 문구를 함께 넣는다.
- 유료 구독(포스타입)을 SNS 에서 직접 팔지 않는다. 무료 → 무료 → 유료 순서를 지킨다.
  SNS 에서 곧장 결제를 요구하면 유입 자체가 끊긴다.
- 글 하나에 CTA 하나. 텔레그램과 포스타입을 같은 글에서 동시에 밀지 않는다.

## 하지 말 것

- 승인 없이 `--live` 실행
- `marketing/.env` 나 토큰을 커밋
- 인스타 media 없이 발행 시도
- 큐의 `results`, `leads.json` 을 손으로 수정 (스크립트가 관리한다)
- `brand.json` 의 `banned` 표현 사용 — 특히 수익 보장·단정 표현은 플랫폼 정책과
  광고 규제 양쪽에 걸린다
